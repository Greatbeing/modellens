ModelLens

See which of your models actually works.

An MCP server that turns any OpenAI-compatible gateway into an observable, rankable set of models. It discovers what a provider advertises, probes what works right now — latency, success, cancellation, streaming, tool calling — keeps the history, and answers "which model should I use?"

Zero third-party dependencies. Python 3.9+ standard library only.

Install and point it at your gateway

# 1. get it
curl -fsSL https://example.com/modellens/modellens.py -o modellens.py

# 2. say where your models live
cat > config.json <<EOF
{"endpoints": [
  {"name": "magpie", "base_url": "http://127.0.0.1:3425/v1"},
  {"name": "openai", "base_url": "https://api.openai.com/v1", "api_key": "sk-..."}
]}
EOF

# 3. probe
python3 modellens.py --config config.json --data history.json --once probe --limit 20

Or use it as an MCP server

{
  "mcpServers": {
    "modellens": {
      "command": "python3",
      "args": ["/path/to/modellens.py",
               "--config", "/path/to/config.json",
               "--data",   "/path/to/history.json"]
    }
  }
}

How it scores

Every probe is a real request, so the numbers are evidence, not estimates.

signalweightnote
Success rate50%0% success ⇒ score 0, whatever else looks good
Median latency30%linear to 0 at 8 s
Cancellation rate20%timeouts and client cancels
Honest notes. Probing costs tokens — each probe is a real completion, so keep the limit sensible. A single probe is weak evidence; the report shows n= so you can see the sample size. And latency is measured from where you run it, so run it from where your agents run.
